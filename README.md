# 糖果坦克大战

用 Godot 4.7 做的糖果主题 Q 版坦克大战，玩法致敬 FC《90 坦克大战》。

## 怎么玩

用 Godot 4.7 打开本目录，按 `F5` 运行。

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 开炮 | 空格 / J / Z / K |
| 暂停 | P / Esc |
| 开始 | 回车 / 空格 |

目标：打掉本关全部 20 辆敌方糖果坦克，同时保护底部的蛋糕基地。按住开炮可持续连发；冰面会打滑；过关后会统计击毁数量。

## 规则（90 坦克大战）

- 砖块饼干可以打穿，硬糖钢板打不穿（火力升到 4 星后可破）
- 果冻水面不能开上去，但炮弹能飞过
- 棉花糖草丛会挡住视线
- 冰面会打滑
- 敌方闪光坦克被打中会掉道具
- 关卡：共 6 关，每关 20 敌，场上最多 4 辆

## 道具

| 道具 | 效果 |
| --- | --- |
| 头盔 | 短暂无敌 |
| 时钟 | 冻结全部敌人 |
| 铲子 | 基地围墙变成钢板 |
| 星星 | 升级火力（连发 / 破钢板） |
| 手雷 | 清掉场上敌人 |
| 坦克 | 加一条命 |
